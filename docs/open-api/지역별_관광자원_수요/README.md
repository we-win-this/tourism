# 지역별 관광자원 수요 API

> 한국관광공사 OpenAPI — 지역별관광자원수요(areaTarResDemService) v4.0

---

## 개요

지역별 관광자원 유형에 대한 소비자 수요를 분석해 제공하는 서비스. 어떤 유형의 관광자원이 해당 지역에서 더 많이 소비되는지 파악할 수 있다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 지역별 자원 유형 수요 조회 | 시군구 기준 관광자원 유형별 수요량 |
| 기간별 수요 변화 | 월·분기 단위 수요 추이 |
| 자원 유형별 전국 비교 | 특정 자원 유형의 지역별 수요 순위 |

---

## 관광자원 유형 분류

| 유형 | 설명 |
|------|------|
| 자연 관광 | 산·바다·계곡 등 자연 자원 |
| 역사·문화 | 문화재·박물관·전통 마을 |
| 레저·스포츠 | 레포츠·테마파크·캠핑 |
| 음식·쇼핑 | 지역 음식·시장·특산품 |
| 축제·행사 | 지역 축제·공연 이벤트 |

---

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/areaTarResDemService/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `areaTarResDem` | 지역별 관광자원 유형별 수요 조회 |

### 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |
| `areaCd` |  | 시도 코드 |
| `signguCd` |  | 시군구 코드 |
| `ydm` |  | 기준 연월 (형식: YYYYMM) |

### 주요 응답 필드

| 필드 | 설명 |
|------|------|
| `areaCd` | 시도 코드 |
| `signguCd` | 시군구 코드 |
| `areaNm` | 지역명 |
| `tarResCd` | 관광자원 유형 코드 |
| `tarResNm` | 관광자원 유형명 |
| `demCnt` | 수요량 (건수) |
| `baseYm` | 기준 연월 |
