# 지역별관광다양성 API — 데이터 준비 중

> 한국관광공사 AreaTarDivService · areaTouDivList
> 파라미터: areaCd=11, baseYm=202412

## 개요

지역 관광 콘텐츠의 다양성 지수를 시군구 단위로 측정 · 관광 매력도 지표로 활용.

---

## 현재 상태

> **총 건수: 0** — 한국관광데이터랩(datalab.visitkorea.or.kr) 집계 데이터가 아직 배포되지 않은 상태입니다.  
> API 키 승인 완료 · 엔드포인트 정상 · 데이터 공급 대기 중.

서비스 키가 정상 승인되어 있고 `resultCode=0000` 응답을 반환하지만,  
백엔드 데이터 소스(관광데이터랩 월별 집계)가 해당 기간에 아직 적재되지 않아 `totalCount=0`.

---

## 예상 응답 필드

| 필드 | 설명 |
|------|------|
| `areaCd` | 시도 코드 |
| `signguCd` | 시군구 코드 |
| `areaNm` | 시도명 |
| `signguNm` | 시군구명 |
| `touDivIdx` | 관광 다양성 지수 |
| `touDivGrd` | 다양성 등급 |
| `baseYm` | 기준 연월 |

### 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `areaCd` | ✓ | 시도 코드 (2자리, 예: `11`=서울) |
| `signguCd` |  | 시군구 코드 (5자리, 예: `11530`=구로구) |
| `baseYm` | ✓ | 기준 연월 (YYYYMM, 예: `202412`) |

---

## 데이터 확인 방법

```bash
python3 fetch_all.py  # baseYm을 최신 월로 변경 후 재실행
```

데이터가 적재되면 `data/result.json` 이 자동으로 갱신됩니다.
