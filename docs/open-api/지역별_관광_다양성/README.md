# 지역별 관광 다양성 API

> 한국관광공사 OpenAPI — 지역별관광다양성(areaTarDivService) v4.0

---

## 개요

지역별 관광자원의 다양성 지수를 제공하는 서비스. 특정 지역이 얼마나 다양한 유형의 관광 자원을 보유하고 있는지 수치로 확인할 수 있다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 지역별 다양성 지수 조회 | 시도·시군구 기준 관광 다양성 점수 |
| 유형별 분포 조회 | 관광지·음식·숙박·문화시설 등 유형별 비중 |
| 전국 순위 조회 | 다양성 지수 상위 지역 순위 |

---

## 다양성 측정 기준 (예시)

| 관광자원 유형 | 포함 항목 |
|--------------|----------|
| 자연 | 산, 계곡, 해변, 섬 |
| 문화 | 박물관, 문화재, 공연장 |
| 레저 | 레포츠, 테마파크, 캠핑 |
| 음식 | 지역 특산 음식, 맛집 밀집도 |
| 숙박 | 호텔·펜션·캠핑 등 유형 다양성 |

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/areaTarDivService/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `areaTarDiv` | 지역별 관광자원 다양성 지수 조회 |

### 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |
| `areaCd` |  | 시도 코드 |
| `signguCd` |  | 시군구 코드 |
| `ydm` |  | 기준 연월 (형식: YYYYMM) |

### 주요 응답 필드

| 필드 | 설명 |
|------|------|
| `areaCd` | 시도 코드 |
| `signguCd` | 시군구 코드 |
| `areaNm` | 지역명 |
| `divIdx` | 다양성 지수 |
| `natRank` | 전국 순위 |
| `tarTypeRto` | 관광자원 유형별 비중 (JSON 배열) |
| `baseYm` | 기준 연월 |
