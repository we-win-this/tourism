# 반려동물 동반여행 정보 API

> 한국관광공사 OpenAPI — 반려동물동반여행 서비스 v4.1

---

## 개요

반려동물과 함께 방문 가능한 전국 관광지·숙박·음식점·펜션 등의 정보를 제공하는 서비스.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 반려동물 동반 가능 시설 조회 | 관광지·숙박·음식점·캠핑장 등 유형별 목록 |
| 상세 정보 조회 | 동반 가능 반려동물 종류·크기 제한, 동반 조건 |
| 지역별 조회 | 시도·시군구 기반 필터 |
| 위치 기반 조회 | GPS 좌표 기반 반경 내 동반 가능 시설 |

---

## 주요 제공 정보

- 시설명, 주소, 전화번호, GPS 좌표
- 동반 가능 반려동물 종류 (개·고양이 등)
- 크기·몸무게 제한
- 목줄·케이지 필수 여부
- 입장료 추가 부과 여부
- 전용 공간 유무 (반려동물 운동장, 세척 시설 등)

---

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/PetTravService1/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `areaBasedList1` | 지역 기반 반려동물 동반 가능 시설 목록 조회 |
| `locationBasedList1` | 위치 기반 반려동물 동반 가능 시설 조회 |
| `detailPetTrav1` | 반려동물 동반 상세 조건 조회 |

### 공통 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |

### 엔드포인트별 추가 파라미터

**`areaBasedList1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `areaCode` |  | 시도 코드 |
| `sigunguCode` |  | 시군구 코드 |
| `contentTypeId` |  | 관광타입 코드 |

**`locationBasedList1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `mapX` | ✓ | 경도 (WGS84) |
| `mapY` | ✓ | 위도 (WGS84) |
| `radius` | ✓ | 반경 (단위: m) |

**`detailPetTrav1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `contentId` | ✓ | 시설 고유 ID |

### 주요 응답 필드 (`detailPetTrav1` 기준)

| 필드 | 설명 |
|------|------|
| `contentid` | 시설 고유 ID |
| `acmpyTypeCd` | 반려동물 동반 가능 종류 코드 |
| `acmpyPsblCpAmt` | 동반 가능 마릿수 |
| `acmpyNeedMtr` | 필수 준비물 (목줄·케이지 등) |
| `relaFrnshpCd` | 반려동물 전용시설 유무 |
| `petAcmpyBan` | 동반 금지 구역 |
| `etcAcmpyInfo` | 기타 동반 조건 |
