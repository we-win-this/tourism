# 오디 오디오가이드 관광 API

> 한국관광공사 OpenAPI — 오디(Audio Guide) 서비스 v4.1

---

## 개요

한국관광공사 공식 오디오 가이드 앱 **"오디"** 의 콘텐츠 데이터를 제공하는 API. 전국 관광지의 음성 해설 정보를 조회할 수 있다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 오디오 콘텐츠 목록 조회 | 오디오 해설이 등록된 관광지 목록 |
| 콘텐츠 상세 조회 | 음성 파일 URL, 스크립트(텍스트), 이미지 |
| 지역별 조회 | 시도·시군구 기반 필터 |
| 언어별 조회 | 한국어·영어·중국어·일본어 등 다국어 지원 |

---

## 주요 제공 정보

- 관광지명, GPS 좌표
- 오디오 파일 URL (MP3)
- 해설 스크립트 (텍스트)
- 해설 소요 시간
- 대표 이미지
- 지원 언어 목록

---

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/OudiService1/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `areaBasedList1` | 지역 기반 오디오 콘텐츠 목록 조회 |
| `detailCommon1` | 오디오 콘텐츠 상세정보 조회 |

### 공통 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |

### 엔드포인트별 추가 파라미터

**`areaBasedList1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `areaCode` |  | 시도 코드 |
| `sigunguCode` |  | 시군구 코드 |
| `langCode` |  | 언어 코드: `ko`/`en`/`zh`/`ja` 등 |

**`detailCommon1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `contentId` | ✓ | 오디오 콘텐츠 고유 ID |

### 주요 응답 필드

| 필드 | 설명 |
|------|------|
| `contentid` | 오디오 콘텐츠 ID |
| `title` | 관광지명 |
| `mapx` / `mapy` | 경도 / 위도 |
| `audioUrl` | 오디오 파일 URL (MP3) |
| `script` | 해설 스크립트 (텍스트) |
| `playTime` | 해설 소요 시간 (초) |
| `firstimage` | 대표 이미지 URL |
| `langCode` | 언어 코드 |
