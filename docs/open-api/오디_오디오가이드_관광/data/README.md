# 오디(Odii) 오디오가이드 관광 API — 샘플 데이터

> 한국관광공사 Odii · themeBasedList · 총 2,231건

## 개요

전국 주요 관광지의 **오디오 가이드(음성 해설)** 콘텐츠 목록.  
테마 기반으로 분류되어 있으며 한국어·영어·일본어·중국어·프랑스어 등 다국어 지원 여부를 `langCheck` 필드로 확인 가능.

---

## langCheck 비트 맵

| 비트 위치 | 언어 |
|----------|------|
| 1번째 (MSB) | 한국어 |
| 2번째 | 영어 |
| 3번째 | 일본어 |
| 4번째 | 중국어 |
| 5번째 | 프랑스어 |

예) `langCheck = "11110"` → 한국어·영어·일본어·중국어 지원

### 주요 필드

| 필드 | 설명 |
|------|------|
| `tid` | 테마 ID |
| `tlid` | 테마 내 항목 ID |
| `title` | 관광지명 |
| `themeCategory` | 테마 카테고리 |
| `addr1` / `addr2` | 시도 / 시군구 |
| `mapX` / `mapY` | 경도 / 위도 |
| `langCheck` | 지원 언어 비트마스크 (5자리) |
| `imageUrl` | 대표 이미지 URL |
