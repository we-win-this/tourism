# 관광채용 정보 API

> 한국관광공사 OpenAPI — 관광채용정보 서비스 v4.0

---

## 개요

관광업 분야 채용 공고 정보를 제공하는 서비스. 호텔·여행사·관광안내소 등 관광 관련 직종의 구인 정보를 조회할 수 있다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 채용공고 목록 조회 | 현재 모집 중인 관광업 채용 목록 |
| 공고 상세 조회 | 모집 직종, 근무지, 급여, 지원 조건 |
| 지역별 조회 | 시도·시군구 기반 필터 |
| 업종별 조회 | 숙박·여행사·음식점·문화시설 등 업종 분류 |

---

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/RecrtInfoService1/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `areaBasedList1` | 지역 기반 채용공고 목록 조회 |
| `detailCommon1` | 채용공고 상세정보 조회 |

### 공통 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |

### 엔드포인트별 추가 파라미터

**`areaBasedList1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `areaCode` |  | 시도 코드 |
| `sigunguCode` |  | 시군구 코드 |
| `industryTypeCd` |  | 업종 코드 (숙박/여행사/음식점/문화시설 등) |

**`detailCommon1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `contentId` | ✓ | 채용공고 고유 ID |

### 주요 응답 필드

| 필드 | 설명 |
|------|------|
| `contentid` | 채용공고 고유 ID |
| `companyNm` | 기업명 |
| `jobTitle` | 모집 직종명 |
| `addr` | 근무지 주소 |
| `salary` | 급여 조건 |
| `deadline` | 모집 마감일 |
| `industryTypeCd` | 업종 코드 |
| `contactTel` | 연락처 |
