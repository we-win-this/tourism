# 두루누비 길코스 여행정보 API — 샘플 데이터

> 한국관광공사 Durunubi · courseList · 총 228건

## 개요

**두루누비**(www.durunubi.kr)에서 제공하는 전국 도보·자전거 길 코스 정보.  
남파랑길·해파랑길·서해랑길 등 장거리 트레킹 루트와 지역 테마 코스를 포함.

### 코스 상세 정보 구조

```
코스
├── 개요 (crsSummary)       — 1~2문장 요약
├── 상세 설명 (crsContents) — 경관·특징 설명
├── 여행 정보 (crsTourInfo) — 주요 명소 목록
├── 교통 정보 (travelerinfo)— 시점·종점·대중교통
└── GPX 경로 (gpxpath)     — GPS 트랙 파일 URL
```

### 주요 필드

| 필드 | 설명 |
|------|------|
| `routeIdx` | 루트 ID |
| `crsIdx` | 코스 ID |
| `crsKorNm` | 코스 한글명 |
| `crsDstnc` | 거리 (km) |
| `crsTotlRqrmHour` | 총 소요 시간 (분) |
| `crsLevel` | 난이도 코드 (1·2·3) |
| `crsCycle` | 순환형 / 비순환형 |
| `sigun` | 시군 위치 |
| `gpxpath` | GPX 파일 URL |
