# 두루누비 길코스 여행정보 API

> 한국관광공사 OpenAPI — 두루누비 서비스 v4.1

---

## 개요

걷기·자전거·MTB·카약 등 **인간의 힘을 이용한 레저여행** 코스 정보를 중심으로 주변 관광정보를 종합 제공하는 통합 여행정보 서비스.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 길 정보 조회 | 전국 둘레길·트레킹로·자전거길 등 코스 목록 |
| 코스 상세 정보 | 코스명, 총거리, 소요시간, 난이도, 출발·도착지 좌표 |
| 코스 경로 정보 | GPX/좌표 형태의 경로 데이터 |
| 주변 관광정보 연계 | 코스 인근 관광지·숙박·음식점 정보 |
| 지역별 조회 | 시도·시군구 코드 기반 코스 목록 필터링 |

---

## 코스 유형

| 유형 | 예시 |
|------|------|
| 걷기 | 제주 올레길, 지리산 둘레길 |
| 자전거 | 4대강 자전거길, 동해안 자전거길 |
| MTB | 산악 자전거 코스 |
| 복합 | 걷기+자전거 혼합 코스 |

---

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/TrailInfoService1/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `trailInfoList1` | 길코스 목록 조회 |
| `trailInfoDetail1` | 길코스 상세정보 조회 |

### 공통 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |

### 엔드포인트별 추가 파라미터

**`trailInfoList1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `areaCode` |  | 시도 코드 |
| `sigunguCode` |  | 시군구 코드 |
| `trailTypeCd` |  | 코스 유형 코드 (걷기/자전거/MTB 등) |

**`trailInfoDetail1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `contentId` | ✓ | 코스 고유 ID |

### 주요 응답 필드

| 필드 | 설명 |
|------|------|
| `contentid` | 코스 고유 ID |
| `trailName` | 코스명 |
| `trailTypeCd` | 코스 유형 코드 |
| `totalDistance` | 총 거리 (km) |
| `requiredTime` | 소요 시간 (분) |
| `difficulty` | 난이도 (상/중/하) |
| `startMapX` / `startMapY` | 출발지 경도 / 위도 |
| `endMapX` / `endMapY` | 도착지 경도 / 위도 |
| `gpxPath` | GPX 경로 파일 URL |
