# 기초지자체 중심관광지 정보 API

> 한국관광공사 OpenAPI — 기초지자체_중심관광지정보 서비스 v4.1

---

## 개요

전국 기초지자체(시·군·구) 단위별로 해당 지역을 대표하는 중심 관광지 정보를 제공하는 서비스.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 지자체별 중심관광지 조회 | 시군구 코드 기준 해당 지역 대표 관광지 목록 |
| 중심관광지 상세 조회 | 관광지 설명, 위치, 대표 이미지 |
| 인근 관광지 연계 | 중심관광지 기준 주변 관광지 목록 |

---

## 주요 제공 정보

- 시군구 코드, 지역명
- 중심관광지명, GPS 좌표, 주소
- 관광지 설명 (공식 소개문)
- 대표 이미지 URL
- 중심관광지 선정 기준 점수

---

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/GunTarService1/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `areaBasedList1` | 지자체별 중심관광지 목록 조회 |
| `detailCommon1` | 중심관광지 상세정보 조회 |

### 공통 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |

### 엔드포인트별 추가 파라미터

**`areaBasedList1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `areaCode` |  | 시도 코드 |
| `sigunguCode` |  | 시군구 코드 |

**`detailCommon1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `contentId` | ✓ | 관광지 고유 ID |

### 주요 응답 필드

| 필드 | 설명 |
|------|------|
| `contentid` | 관광지 고유 ID |
| `title` | 중심관광지명 |
| `addr1` | 주소 |
| `mapx` / `mapy` | 경도 / 위도 |
| `firstimage` | 대표이미지 URL |
| `overview` | 관광지 공식 소개문 |
| `areacode` / `sigungucode` | 시도 / 시군구 코드 |
