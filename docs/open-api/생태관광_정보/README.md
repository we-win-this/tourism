# 생태관광 정보 API

> 한국관광공사 OpenAPI — 생태관광 서비스 v4.2

---

## 개요

환경부 지정 생태관광지역을 포함한 전국 생태관광 명소 정보를 제공하는 서비스. 자연환경 보전과 지속 가능한 관광을 지향하는 생태관광 특화 데이터를 제공한다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 생태관광지 목록 조회 | 전국 생태관광 명소 목록 |
| 생태관광지 상세 정보 | 생태 자원 설명, 탐방 프로그램, 운영 정보 |
| 지역별 조회 | 시도·시군구 기반 생태관광지 필터 |
| 탐방 프로그램 정보 | 생태 해설사 동반 프로그램, 체험 프로그램 등 |

---

## 주요 제공 정보

- 생태관광지명, 주소, GPS 좌표
- 생태 자원 유형 (습지·숲·갯벌·철새도래지 등)
- 탐방 가능 시기·시간
- 방문자 수 제한 여부
- 주요 생물 자원 (식물·동물·철새 등)

---

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/EcoTourService1/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `areaBasedList1` | 지역 기반 생태관광지 목록 조회 |
| `detailEcoTour1` | 생태관광지 상세정보 및 탐방 프로그램 조회 |

### 공통 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |

### 엔드포인트별 추가 파라미터

**`areaBasedList1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `areaCode` |  | 시도 코드 |
| `sigunguCode` |  | 시군구 코드 |
| `ecoTourTypeCd` |  | 생태관광 유형 코드 (습지/숲/갯벌 등) |

**`detailEcoTour1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `contentId` | ✓ | 생태관광지 고유 ID |

### 주요 응답 필드

| 필드 | 설명 |
|------|------|
| `contentid` | 생태관광지 고유 ID |
| `title` | 명칭 |
| `addr1` | 주소 |
| `mapx` / `mapy` | 경도 / 위도 |
| `ecoTourTypeCd` | 생태관광 유형 코드 |
| `visitPeriod` | 탐방 가능 시기 |
| `visitLimitYn` | 방문자 수 제한 여부 |
| `programList` | 탐방 프로그램 목록 |
| `mainBio` | 주요 생물 자원 정보 |
