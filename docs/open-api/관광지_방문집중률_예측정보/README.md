# 관광지 방문집중률 예측정보 API

> 한국관광공사 OpenAPI — 관광지집중률방문자추이예측정보 서비스 v4.0

---

## 개요

특정 관광지의 방문자 집중도와 향후 방문 추이를 예측하는 데이터를 제공하는 서비스. 혼잡도 회피 및 최적 방문 시기 안내에 활용된다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 방문자 집중률 조회 | 관광지별 시간대·요일·월별 혼잡도 지수 |
| 방문자 추이 예측 | 향후 N일간 예상 방문자 수 예측값 |
| 지역별 집중률 | 시군구 단위 관광 집중도 비교 |
| 최적 방문 시기 추천 | 혼잡도 낮은 날짜·시간대 추천 |

---

## 주요 제공 정보

- 관광지 코드, 명칭
- 일별·시간대별 방문자 지수 (정규화된 집중도 점수)
- 예측 기간 내 방문자 추이 그래프 데이터
- 시군구 코드 기반 지역 집중도

---

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/TarDsrtRateService1/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `areaBasedList1` | 지역 기반 관광지 집중률 목록 조회 |
| `detailList1` | 특정 관광지의 방문자 추이 예측 데이터 조회 |

### 공통 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |

### 엔드포인트별 추가 파라미터

**`areaBasedList1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `areaCode` |  | 시도 코드 |
| `sigunguCode` |  | 시군구 코드 |

**`detailList1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `contentId` | ✓ | 관광지 고유 ID |

### 주요 응답 필드

| 필드 | 설명 |
|------|------|
| `contentid` | 관광지 고유 ID |
| `title` | 관광지명 |
| `dsrtRate` | 집중률 지수 (정규화된 점수) |
| `baseYmd` | 기준 일자 |
| `baseHour` | 기준 시간대 |
| `predictVisitor` | 예측 방문자 수 |
| `sigunguCode` | 시군구 코드 |
