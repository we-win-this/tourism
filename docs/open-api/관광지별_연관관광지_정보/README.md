# 관광지별 연관관광지 정보 API

> 한국관광공사 OpenAPI — 관광지별연관관광지정보 서비스 v4.1

---

## 개요

특정 관광지를 방문한 사람들이 함께 방문하는 연관 관광지 정보를 데이터 기반으로 제공하는 서비스. 실제 방문 패턴 분석 기반의 추천 데이터.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 연관 관광지 조회 | 특정 관광지 contentId 기준 함께 방문한 관광지 목록 |
| 연관도 순위 | 연관 강도(방문 동반 빈도) 기반 순위 제공 |
| 지역 내/외 연관지 | 같은 지역 또는 다른 지역의 연관 관광지 구분 조회 |

---

## 주요 제공 정보

- 기준 관광지 contentId, 명칭
- 연관 관광지 contentId, 명칭, 주소, GPS 좌표
- 연관도 점수 (0.0 ~ 1.0)
- 연관 관광지 대표 이미지

---

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/TarRlteTarService1/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `areaBasedList1` | 지역 기반 연관관광지 목록 조회 |
| `detailList1` | 특정 관광지의 연관관광지 목록 조회 |

### 공통 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |

### 엔드포인트별 추가 파라미터

**`areaBasedList1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `areaCode` |  | 시도 코드 |
| `sigunguCode` |  | 시군구 코드 |
| `contentTypeId` |  | 관광타입 코드 |

**`detailList1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `contentId` | ✓ | 기준 관광지 고유 ID |

### 주요 응답 필드

| 필드 | 설명 |
|------|------|
| `contentid` | 기준 관광지 ID |
| `rlteTarContentId` | 연관 관광지 ID |
| `rlteTarTitle` | 연관 관광지명 |
| `rlteTarAddr` | 연관 관광지 주소 |
| `rlteTarMapX` / `rlteTarMapY` | 연관 관광지 경도 / 위도 |
| `rlteTarScore` | 연관도 점수 (0.0 ~ 1.0) |
| `rlteTarFirstImage` | 연관 관광지 대표이미지 URL |
