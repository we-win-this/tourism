## 🔍 주요 특징 및 요약

- **계절감:** 겨울의 설경과 운무, 봄의 벚꽃, 가을 단풍 등 한국의 아름다운 사계절을 보여줍니다.
- **다양한 촬영 부문:** 스마트폰 부문 4건, 디지털카메라 부문 4건, 드론 부문 2건 등 다양한 촬영 기법을 활용한 작품들로 구성되었습니다.
- **대표 장소:** 가야산, 덕유산 등 국립공원의 대자연과 대릉원, 구인사 등 역사적·종교적 장소가 돋보입니다.
