# 관광공모전 수상작 정보 API

> 한국관광공사 OpenAPI — 관광공모전 수상작 서비스

---

## 개요

한국관광공사 주관 공모전 수상작 서비스 정보를 제공하는 API. 역대 공모전에서 수상한 관광 서비스·앱·콘텐츠의 정보를 조회할 수 있다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 수상작 목록 조회 | 연도별·부문별 수상작 목록 |
| 수상작 상세 정보 | 서비스 설명, 수상 부문, 수상 연도, 서비스 링크 |
| 부문별 조회 | 웹·앱·데이터 활용 등 부문별 필터 |

---

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/ContestTarService1/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `contestList1` | 공모전 수상작 목록 조회 |

### 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |
| `contestYear` |  | 공모전 연도 (YYYY) |
| `contestTypeCd` |  | 부문 코드 (웹앱/데이터 등) |

### 주요 응답 필드

| 필드 | 설명 |
|------|------|
| `contestId` | 수상작 고유 ID |
| `contestNm` | 서비스명 |
| `contestYear` | 수상 연도 |
| `awardTypeCd` | 수상 부문 코드 |
| `awardTypeNm` | 수상 부문명 |
| `serviceDesc` | 서비스 설명 |
| `serviceLinkUrl` | 서비스 링크 URL |
