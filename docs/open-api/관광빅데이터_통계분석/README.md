# 관광빅데이터 통계분석 API

> 한국관광공사 OpenAPI — 관광빅데이터 서비스 v4.1

---

## 개요

관광 관련 빅데이터를 기반으로 방문자 수, 관광 트렌드, 소비 패턴 등 통계 정보를 제공하는 서비스.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 방문자 통계 | 지역별·기간별 관광객 방문 수 집계 |
| 관광 트렌드 | 검색 트렌드·SNS 언급량 기반 인기 관광지 순위 |
| 소비 패턴 | 관광객 카드 소비 데이터 기반 지역별 소비 현황 |
| 시간대별 유동인구 | 관광지 인근 시간대별 인구 밀도 |
| 체류 시간 분석 | 관광지별 평균 체류 시간 |

---

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/TarStatService1/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `tarStatList1` | 관광빅데이터 통계 목록 조회 |

### 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |
| `areaCode` |  | 시도 코드 |
| `sigunguCode` |  | 시군구 코드 |
| `statsCd` |  | 통계 유형 코드 (방문자수·소비패턴·트렌드 등) |
| `baseYmd` |  | 기준 일자 (형식: YYYYMMDD) |

### 주요 응답 필드

| 필드 | 설명 |
|------|------|
| `areaCode` | 시도 코드 |
| `sigunguCode` | 시군구 코드 |
| `statsCd` | 통계 유형 코드 |
| `statsNm` | 통계 유형명 |
| `statsValue` | 통계값 |
| `baseYmd` | 기준 일자 |
| `rank` | 전국 순위 |
