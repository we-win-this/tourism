# 지역별 관광수요 강도 API

> 한국관광공사 OpenAPI — 지역별관광수요강도(areaTarDemDsService) v4.0

---

## 개요

지역별 관광 수요의 강도(intensity)를 정량적으로 제공하는 서비스. 특정 지역에 대한 관광 관심도와 수요 크기를 수치로 확인할 수 있다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 지역별 수요 강도 조회 | 시도·시군구 기준 관광 수요 강도 지수 |
| 기간별 비교 | 월별·분기별 수요 강도 추이 비교 |
| 전국 순위 조회 | 수요 강도 상위 지역 순위 |

---

## 주요 제공 정보

- 시군구 코드, 지역명
- 수요 강도 지수 (정규화된 0~100 점수)
- 집계 기준 기간 (월)
- 전국 대비 상대 순위

---

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/areaTarDemDsService/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `areaTarDemDs` | 지역별 관광 수요 강도 지수 조회 |

### 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |
| `areaCd` |  | 시도 코드 |
| `signguCd` |  | 시군구 코드 |
| `ydm` |  | 기준 연월 (형식: YYYYMM) |

### 주요 응답 필드

| 필드 | 설명 |
|------|------|
| `areaCd` | 시도 코드 |
| `signguCd` | 시군구 코드 |
| `areaNm` | 지역명 |
| `demDsIdx` | 수요 강도 지수 (0~100 정규화) |
| `natRank` | 전국 순위 |
| `baseYm` | 기준 연월 |
