# 무장애 배리어프리 여행정보 API

> 한국관광공사 OpenAPI — 무장애여행 서비스 v4.3

---

## 개요

장애인·고령자·유아 동반 가족 등 이동 약자가 편리하게 방문할 수 있는 전국 무장애(배리어프리) 관광지 정보를 제공하는 서비스.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 무장애 관광지 목록 조회 | 배리어프리 인증·지정 관광지 목록 |
| 시설별 접근성 정보 | 휠체어 접근 가능 여부, 점자 안내, 청각 지원 등 세부 항목 |
| 장애 유형별 필터 | 지체장애·시각장애·청각장애·노인·유아 동반별 필터 |
| 지역별 조회 | 시도·시군구 기반 필터 |

---

## 주요 제공 정보

- 주차장 장애인 전용 구역 유무
- 출입구 턱 제거·경사로 설치 여부
- 휠체어 대여 가능 여부
- 점자 안내판·음성 안내 유무
- 장애인 화장실 유무
- 엘리베이터·리프트 설치 여부
- 안내견 동반 가능 여부

---

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/BarrFreeTrailService1/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `areaBasedList1` | 지역 기반 무장애 관광지 목록 조회 |
| `detailBarrFree1` | 무장애 시설 접근성 상세 조회 |

### 공통 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |

### 엔드포인트별 추가 파라미터

**`areaBasedList1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `areaCode` |  | 시도 코드 |
| `sigunguCode` |  | 시군구 코드 |
| `contentTypeId` |  | 관광타입 코드 |

**`detailBarrFree1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `contentId` | ✓ | 관광지 고유 ID |
| `contentTypeId` | ✓ | 관광타입 코드 |

| `chkSignlanGuide` | 수어 안내 서비스 유무 |
| `chkBrailleGuide` | 점자 안내판 유무 |
