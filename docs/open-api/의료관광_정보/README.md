# 의료관광 정보 API

> 한국관광공사 OpenAPI — 의료관광 서비스 v4.1

---

## 개요

외국인 환자를 대상으로 하는 국내 의료관광 인증 병원·의원·클리닉 정보를 제공하는 서비스.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 의료관광 기관 목록 조회 | 한국관광공사 인증 의료관광 기관 목록 |
| 기관 상세 정보 조회 | 진료과목, 외국어 서비스, 연락처, 위치 |
| 지역별 조회 | 시도·시군구 기반 필터 |
| 진료과목별 조회 | 성형·피부·치과·한방·검진 등 유형 분류 |

---

## 주요 제공 정보

- 의료기관명, 주소, 전화번호, 홈페이지
- 인증 구분 (우수·일반)
- 진료과목 목록
- 지원 외국어 (영어·중국어·일본어 등)
- 국제 인증 여부

---

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/MedTourService1/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `areaBasedList1` | 지역 기반 의료관광 기관 목록 조회 |
| `detailMedTour1` | 의료관광 기관 상세정보 조회 |

### 공통 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |

### 엔드포인트별 추가 파라미터

**`areaBasedList1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `areaCode` |  | 시도 코드 |
| `sigunguCode` |  | 시군구 코드 |
| `medTypeCd` |  | 진료과목 유형 코드 (성형/피부/치과/한방/검진 등) |

**`detailMedTour1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `contentId` | ✓ | 의료기관 고유 ID |

### 주요 응답 필드

| 필드 | 설명 |
|------|------|
| `contentid` | 의료기관 고유 ID |
| `title` | 기관명 |
| `addr1` | 주소 |
| `mapx` / `mapy` | 경도 / 위도 |
| `certGrade` | 인증 구분 (우수/일반) |
| `medTypeCdList` | 진료과목 코드 목록 |
| `langList` | 지원 외국어 목록 |
| `intlCertYn` | 국제 인증 여부 |
| `tel` | 전화번호 |
| `homepage` | 홈페이지 URL |
