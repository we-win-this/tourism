# 고캠핑 캠핑장 여행정보 API

> 한국관광공사 OpenAPI — 고캠핑 서비스 v4.1

---

## 개요

전국 캠핑장(일반캠핑장·오토캠핑장·글램핑·카라반 등) 정보를 제공하는 서비스.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 캠핑장 목록 조회 | 지역별·유형별 캠핑장 전체 목록 |
| 캠핑장 상세 정보 | 시설 현황, 입지 환경, 부대시설, 예약 정보 |
| 주변 관광정보 연계 | 캠핑장 인근 관광지·음식점 정보 |
| 키워드 검색 | 캠핑장명·지역명으로 검색 |

---

## 캠핑 유형

| 유형 | 설명 |
|------|------|
| 일반야영장 | 텐트 설치 가능한 일반 캠핑장 |
| 오토캠핑장 | 차량 진입 가능한 캠핑장 |
| 글램핑 | 시설 완비된 고급 캠핑 |
| 카라반 | 카라반 전용 주차 캠핑장 |
| 복합 | 여러 유형 혼합 운영 |

---

## 주요 제공 정보

- 주소, GPS 좌표, 전화번호, 홈페이지
- 사이트 수, 화장실·샤워실 유무
- 반려동물 동반 가능 여부
- 예약 방법 (현장/온라인/전화)
- 주변 자연환경 (해변·계곡·숲·산 등)

---

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/GoCamping/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `basedList` | 캠핑장 전체 목록 조회 |
| `searchList` | 키워드·지역 기반 캠핑장 검색 |
| `imageList` | 캠핑장별 이미지 목록 조회 |
| `locationBasedList` | 위치(GPS) 기반 캠핑장 조회 |

### 공통 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |

### 엔드포인트별 추가 파라미터

**`searchList`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `keyword` | ✓ | 검색 키워드 (캠핑장명·지역명) |
| `do` |  | 도 명칭 |
| `sigunguNm` |  | 시군구 명칭 |

**`locationBasedList`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `mapX` | ✓ | 경도 (WGS84) |
| `mapY` | ✓ | 위도 (WGS84) |
| `radius` | ✓ | 반경 (단위: m) |

**`imageList`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `contentId` | ✓ | 캠핑장 고유 ID |

### 주요 응답 필드

| 필드 | 설명 |
|------|------|
| `contentId` | 캠핑장 고유 ID |
| `facltNm` | 캠핑장명 |
| `addr1` | 주소 |
| `mapX` / `mapY` | 경도 / 위도 |
| `induty` | 캠핑 유형 (일반야영장·오토캠핑장·글램핑·카라반) |
| `siteCo` | 사이트 총 수 |
| `animalCmgCl` | 반려동물 동반 가능 여부 |
| `resveCl` | 예약 방법 (현장·온라인·전화) |
| `tel` | 전화번호 |
| `homepage` | 홈페이지 URL |
