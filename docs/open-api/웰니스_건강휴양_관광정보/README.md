# 웰니스 건강휴양 관광정보 API

> 한국관광공사 OpenAPI — 웰니스 서비스 v4.1

---

## 개요

명상·치유·힐링·스파·한방 등 건강과 휴양을 목적으로 하는 **웰니스 관광** 정보를 제공하는 서비스.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 웰니스 관광지 목록 조회 | 전국 웰니스 인증 시설·지역 목록 |
| 프로그램 정보 조회 | 명상·요가·스파·한방 치유 등 체험 프로그램 |
| 지역별 조회 | 시도·시군구 기반 필터 |
| 유형별 조회 | 자연 치유·온천·한방·마음 치유·운동 등 유형 분류 |

---

## 웰니스 유형

| 유형 | 예시 |
|------|------|
| 자연 치유 | 삼림욕, 해수 치유, 공기 요법 |
| 온천·스파 | 온천 목욕, 머드 스파 |
| 한방 치유 | 한방 체험, 약초 요법 |
| 마음 치유 | 명상, 요가, 템플스테이 |
| 운동·레포츠 | 헬스 리조트, 수중 치유 |

---

## API 명세

**Base URL**: `https://apis.data.go.kr/B551011/WellnessTourService1/`

### 엔드포인트

| 오퍼레이션 | 설명 |
|-----------|------|
| `areaBasedList1` | 지역 기반 웰니스 관광지 목록 조회 |
| `detailWellness1` | 웰니스 시설 상세정보 및 프로그램 조회 |

### 공통 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | ✓ | 발급받은 API 인증키 (URL encoding) |
| `MobileOS` | ✓ | OS 구분: `ETC` / `AND` / `IOS` / `WIN` |
| `MobileApp` | ✓ | 서비스(앱) 명칭 |
| `_type` |  | 응답 형식: `json` / `xml` (기본: xml) |
| `numOfRows` |  | 페이지당 결과 수 |
| `pageNo` |  | 페이지 번호 |

### 엔드포인트별 추가 파라미터

**`areaBasedList1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `areaCode` |  | 시도 코드 |
| `sigunguCode` |  | 시군구 코드 |
| `wellnessTypeCd` |  | 웰니스 유형 코드 (자연치유/온천/한방/마음치유/운동) |

**`detailWellness1`**

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `contentId` | ✓ | 웰니스 시설 고유 ID |

### 주요 응답 필드

| 필드 | 설명 |
|------|------|
| `contentid` | 시설 고유 ID |
| `title` | 시설명 |
| `addr1` | 주소 |
| `mapx` / `mapy` | 경도 / 위도 |
| `wellnessTypeCd` | 웰니스 유형 코드 |
| `programList` | 체험 프로그램 목록 |
| `openTime` | 운영 시간 |
| `tel` | 전화번호 |
| `firstimage` | 대표 이미지 URL |
